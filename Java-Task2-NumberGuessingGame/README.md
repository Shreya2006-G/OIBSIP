# Number Guessing Game 

## About the Project
A console-based Number Guessing Game developed using Java as part of the Oasis Infobyte Java Development Internship.

The computer generates a random number, and the player has to guess it within a limited number of attempts.

## Features
- Random number generation.
- Three difficulty levels: Easy, Medium, and Hard.
- Four hints: Too Low, Low, High, and Too High.
- Limited attempts based on difficulty.
- Win and lose conditions.
- Option to play multiple rounds.
- Input validation.

## Technologies Used
- Java
- IntelliJ IDEA
- Random class
- Scanner class

## Difficulty Levels

| Level | Number Range | Attempts |
|---|---|---|
| Easy | 1–50 | 10 |
| Medium | 1–100 | 7 |
| Hard | 1–200 | 5 |

## How to Run
1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Open `Main.java`.
4. Run the Main class.
5. Select a difficulty and start guessing!
