## 🚀 Projects

### 1. Little Journeys – Online Reservation System
A Java-based online reservation system that allows users to log in, enter reservation details, and manage booking information.

**Key Features:**
- User Login and Authentication
- Login Validation
- Reservation Form
- Unique PNR Generation
- SQLite Database Connectivity
- Booking Confirmation
- Reservation Data Storage

**Technologies:** Java, Java Swing, JDBC, SQLite, Maven

📂 [View Project](./Java-Task1-OnlineReservationSystem)

### 2. Number Guessing Game
A console-based Java game where the computer generates a random number and the player attempts to guess it within a limited number of attempts.

**Key Features:**
- Random Number Generation
- User Input Handling
- Limited Guess Attempts
- Higher or Lower Hints
- Game Result Display

**Technologies:** Java

📂 [View Project](./Java-Task2-NumberGuessingGame)
